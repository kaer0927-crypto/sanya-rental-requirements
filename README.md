# 三亚市不动产租赁管理需求

> 三亚市直单位办公用房及技术业务用房**租用台账**产品需求与原型材料库。
> 本仓库为需求阶段交付物集合（PRD / 需求评审 / 原型 / 截图 / 原始填报表），非可运行的工程代码仓库。

---

## 一、项目背景

三亚市机关事务管理局对市直单位办公用房及技术业务用房租赁情况开展摸底，由各单位线下填报 Excel 统计表（附件5《租用信息汇总表》），真实填报 **46 条 / 40 余家单位**，存在以下治理难题：

- 面积、租金约 1/3 为自由文本，无法直接求和；
- 枚举发散（单位性质、租赁用途存在错字、缩写、多种写法）；
- 12 条未备案、3 条备案信息空缺，督办依赖人工筛查；
- 全部租赁房源为**外部房产**，现有办公用房系统按「自有房产」标准建档，外部租赁房源录不进去。

**客户核心诉求**：让附件5 这张表「进得去、出得来」——一次性导入系统形成台账，能按原口径导出还原，不必逐条手工建档。

## 二、本期范围

一期（本次交付）在系统现有【租用合同管理】基础上迭代，新增**【租用记录管理】**菜单
（办公用房 → 业务办理 → 租赁管理 → 租用管理）：

| 能力 | 说明 |
|------|------|
| 租用记录台账 | 列表 + 页头统计 + 双行筛选（附件5 完整 16 列口径） |
| 批量导入 | 含脏数据归一化兜底（枚举纠错、数值年化、文本保留） |
| 导出 | 数据一致即可，不还原盖章样式 |
| 新增 / 编辑 | 整页五模块表单（基础信息 / 关联租赁资产等） |
| 详情 | 独立整页（非抽屉），三区块只读展示 |
| 关联租赁资产 | 房间 / 楼层 / 整栋 三类型可并存，右侧抽屉提交 |

**明确不做（二期规划）**：合同衔接（补录 / 关联合同）、修改操作日志、单位在线填报。

## 四、原型使用方式

原型为**纯前端单文件 HTML**（无后端、无依赖），直接用浏览器打开即可：

```bash
open "workspace/租用台账原型_v4.html"
```

演示数据为附件5 中的前 10 条真实填报（评审演示用），导入 / 导出等交互均为前端模拟。
