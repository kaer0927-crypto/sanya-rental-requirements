## 菜单一：租用合同管理

### 1.1 租用合同列表

| 项 | 说明 |
|---|---|
| 列表字段 | 合同编号 / 租用单位 / 单位性质 / 租赁地址 / 出租方 / 租赁用途 / 租赁期限 / 年租金(元) / 租金来源 / 是否备案 / 租用来源（合同导入 · 手工创建）/ 创建时间 |

| 入口按钮 | 右上角「+ 新增合同」「批量导入」 |

### 1.2 合同导入（向导弹窗，交互与现有导入一致）

| 步骤 | 功能 | 说明 |
|---|---|---|
| ① 模板下载 | 按客户实际填报字段集 | 单位名称 / 单位性质 / 租赁地址 / 租赁建筑面积-合计 / 办公用房㎡ / 业务用房㎡ / 出租方 / 租赁用途 / 租赁期限 / 年租金 / 租金来源 / 是否备案 / 联系人 / 联系电话 / 备注 |
| ② 上传与校验 | .xlsx 上传，列名自动匹配 | 校验必填缺失、字典值（单位性质 / 租赁用途 / 租金来源 / 是否备案）、数值格式；产出校验报告（通过 / 失败 / 警告） |
| ③ 导入预览 | 逐行预览 | ⚠ **地址歧义标注（核心）**：每行提示「系统无法判定该地址对应楼栋 / 楼层 / 房间，空间归属待确认」，行状态 =「待确认」 |
| ④ 台账生成配置 | 「导入后自动生成租用台账：是 / 否」 | **原型中醒目标记为待客户确认**（系统无法仅凭地址判定归属，生成规则需客户拍板） |
| ⑤ 执行与结果 | 每行生成：合同记录 + 租用记录（租用来源 = 合同导入） | 结果页：成功 / 失败 / 待确认数量汇总；失败行可导出修正后重导 |

### 1.3 合同创建（表单）

| 区块 | 功能 | 说明 |
|---|---|---|
| 基础信息 | 沿用现有表单字段 | 合同编号 / 租用单位 / 单位性质 / 出租方 / 租赁用途 / 租赁期限 / 年租金 / 押金 / 租金来源 / 是否备案 / 联系人 / 联系电话 / 备注 |
| 资产信息 · 方式一：**直接填写（新增，主推）** | 租赁地址（文本）、租赁建筑面积-合计（㎡）、办公用房面积（㎡）、业务用房面积（㎡） | 字段定义与导入模板完全一致 |
| 面积校验 | 合计 与 办公+业务 的关系 | 规则待确认（建议：合计 = 办公 + 业务，自动合计可修正） |
| 资产信息 · 方式二：选择已有资产 | 原资产选择器 | 范围 = 自建台账资产；**是否保留待确认** |
| 保存后归属 | 自动生成租用记录 | 「租用来源 = 手工创建」，归入租用台账，与合同双向关联 |
| 一致性保证 | 两条路径同结构 | 直接填写与导入共用同一套字段字典、校验规则、落库结构 |
